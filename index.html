Projects

GraphIt

Native desktop app in Python for visualising stock-market data. It combines Streamlit and Plotly inside PyWebView, with a local SQLite cache, date-range filtering, a choice of chart types, multi-company comparison on one chart and saved configuration.

Python, Streamlit, Plotly, PyWebView, SQLite, yfinance

OLX Offer Tracker

An experimental scraping and automation tool for monitoring listings on OLX.pl. It drives a Chromium browser with Playwright, handles dynamically loaded results, sorting options and category filters, collects and normalises listing URLs, and separates new offers from ones saved earlier, with a separate listing file per search topic. The long-term idea was automated deal finding, for example comparing second-hand LEGO prices with BrickLink; Telegram alerts, a SQLite store and more marketplaces are planned but not built yet.

Python, Playwright, BeautifulSoup, Chromium

DailyNews

An automated pipeline designed to turn stories from Medium Daily Edition into vertical 9:16 YouTube Shorts (1080×1920, MP4). The planned flow is scraping, article extraction, local-LLM script writing, AI voice-over, video rendering, validation and automatic upload, all running on self-hosted models to avoid paid cloud APIs. The README lists Ollama, Whisper, Piper / XTTS and FFmpeg as potential building blocks.

Python, local LLMs, FFmpeg, automation

Slime Farm

My first larger programming project: an idle game in Java where you hatch eggs, collect slimes of different tiers, earn passive coins, buy upgrades and drag slimes around your farm. Progress is saved automatically. Built with Swing and AWT (rendering, mouse input, collision detection), ImageIO sprites, custom graphics and WAV sound. It taught me game loops, OOP structure, file handling and organising a bigger codebase.

Java, Swing, AWT, game development

Functions

A small program that animates the graphs of sin, cos, tangent and cotangent. Drawing is keyboard-controlled: Space starts drawing, and S, C, T and G start sine, cosine, tangent and cotangent individually, so you can watch several functions being drawn at once. A ready-to-run .exe is included in the release folder.

Maths visualisation, keyboard controls

rust_game_of_life

Two cellular automata in Rust: Conway's Game of Life and Langton's Ant. In Game of Life you set the number of starting squares, then press Space to run the simulation. For Langton's Ant you set the starting squares to 0 and press A to release the ant. A ready-to-run .exe is included in the release folder.

Rust, cellular automata, simulation
